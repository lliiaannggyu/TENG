## TENG 文件管理器（Wear OS 圆屏）— 从脚手架到完整实现

**背景**：项目初始只有一个 `FileManagerRoundScreen` 演示页（圆环 + 3 个按钮），
需求是完整的圆屏手表文件管理器方案（浏览/筛选/排序/多选/复制粘贴/压缩/APK/局域网/查看器）。

**决策与产出**

- 圆屏布局：根布局改 `boxedEdges="none"` 全屏铺满，安全区交给 Compose
  （`RoundMetrics`：R = D/2 × 0.88 + 极坐标 `CircularStage` + `ScalingLazyColumn` 自带边缘缩放）。
  原因：`boxedEdges="all"` 把 216dp 压成 152.8dp，文件名被截断到无法区分同批照片。
- 存储：沙盒 `java.io.File` + SAF `DocumentsContract` 双通道；**不用** `DocumentFile.listFiles()`
  （N+1 次跨进程查询）。`Location` 必须携带 `treeUri`，否则 SAF 子目录无法继续下钻。
- 权限：不申请 `MANAGE_EXTERNAL_STORAGE` / `READ_MEDIA_*`；合规理由写在 docs。
- 压缩：ZIP 写用 commons-compress（字节级进度/取消），ZIP 读用 zip4j（AES/分卷/流式），
  7z 用 commons-compress。7z 加密创建明确不支持并在 UI 提示。
- 局域网：自定义 TCP 帧协议（4B 长度 + JSON），NSD 发现，内容 id 断点续传 + 落盘后整体 SHA-256 校验。
- 32 个 Kotlin 文件 / ~7.8k 行；文档 `docs/架构与交互设计.md`（含 Play 合规话术、验收清单）。

**踩过的坑（重要，避免重复）**

1. `ArchiveEngine.stage()` 早期版本在 `finally` 里无条件删除，会把用户 `file://` 源压缩包删掉 →
   改为 `Staged(file, isTemp)`，只删自己复制出来的临时副本。
2. "移动"的撤销不能实现成"删除新位置"（会丢数据）→ 撤销只对 COPY 提供 `DeleteCreated`。
3. `LanTransfer.shutdown()` 不能用 `cancelAndJoin`（挂起函数），改 `cancel()`。
4. Wear M3 的 `ColorScheme` 没有 `tertiary` 槽位；`darkColorScheme` 只能传确定存在的槽位。
5. Coil `memoryCache {}` 的 lambda 返回 `MemoryCache` 与 `(Builder.()->Unit)` 重载不匹配，
   改为显式传对象。
6. 局部函数引用 `::emit` 风险高 → 改成显式 lambda。
7. 读目录 / 判可写 / 回收站统计都是跨进程调用，必须挪到 `Dispatchers.IO`（含 `init` 与组合期调用）。

## 打包验证（同日）

环境坑：`JAVA_HOME` 指向 `jdk-17.0.9.9-hotspot`（不存在），实际是 `jdk-17.0.18.8-hotspot`，
构建前必须 `export JAVA_HOME="/c/Program Files/Eclipse Adoptium/jdk-17.0.18.8-hotspot"`。

编译暴露并修复的 8 类真实错误（都是"我以为是这个 API"造成的）：

1. `PackageInstaller.commit(sessionId, IntentSender)` 在 **API 36 已移除**，必须
   `session.commit(intentSender)`（在 `openSession().use{}` 内提交）。
2. zip4j：`AesKeyStrength.AES_256` 实为 `KEY_STRENGTH_256`；**密码挂在 `ZipFile` 上**，
   `ZipParameters` 没有 `setPassword`。
3. commons-compress：`SevenZArchiveEntry.hasStream` 是私有字段（getter 叫 `hasStream()`，
   不满足 Kotlin 属性合成规则），必须 `setHasStream(true)`。
4. Wear M3 **没有 `darkColorScheme()`**，只有 `ColorScheme(...)` 构造器；也没有 `surface` 槽位，
   用 `surfaceContainerLow/…/High` + `onSurfaceVariant` + `outline`。
5. `uniqueName(name, Set)` 第二参是 `(String)->Boolean`，要传 `{ it in taken }`。
6. `interface UndoRecord { val label }` 的实现类必须 `override val label`。
7. `coroutineContext.isActive` 需要 `import kotlinx.coroutines.isActive`。
8. `ScalingLazyColumn` 的 content lambda 不是 @Composable，所有 Composable 调用必须放进 `item {}`。

lint：Media3 的 `PlayerView.controllerShowTimeoutMs / setShowBuffering` 是 `@UnstableApi`，
用 `@androidx.annotation.OptIn(UnstableApi::class)` 标注（直接标 `@UnstableApi` 会传染调用方）。
最终 **0 errors / 66 warnings**（余下是 UnusedResources、版本可升级、UsableSpace 等）。

瘦身：移除了未使用的 `play-services-wearable`（本项目自研局域网协议，不用 Data Layer），
把 `compose-ui-tooling`/`ui-tooling-preview`/`wear-tooling-preview` 从 implementation 改为 debugImplementation。
产物：`app/build/outputs/apk/debug/app-debug.apk` 40.4MB（dex 38MB，debug 未混淆）。
release 若开 R8 预计可降到 ~10-12MB，但未验证运行时，未擅自开启。

## UI 重构为官方 M3E（同日）

需求：去掉首页背景的存储进度环，加入 M3E 时钟组件，全部 UI 优先用官方 M3E。

**结论：`androidx.wear.compose.material3` 就是官方 M3E（Material 3 Expressive for Wear）**，
其中 `TimeText` 就是它的时钟组件；库里**没有** `Clock` 这个类名，别再找。

改动：
- 删除自绘 `ui/round/RoundComponents.kt` + `RoundGeometry.kt`（RingArc / RoundListRow /
  RoundTextAction / RoundIconAction / EdgeScrollRail / CurvedText 全部退役）。
- 新增 `ui/common/M3E.kt`：只保留 M3E 没有的三样（KindBadge / FileCard 的右滑区间选手势 / 底部压暗层）。
- 首页：`AppScaffold` + `ScreenScaffold(timeText = TimeText(maxSweepAngle=96f, 18sp))`，
  存储环删除，改为一张 Card 显示百分比。
- 全部弹层改 `AlertDialog` / `Dialog` + `SegmentedCircularProgressIndicator`。
- 开关改 `SwitchButton`，滚动指示改官方 `ScrollIndicator`。

**两个必须记住的坑**：
1. `ScalingLazyColumn` 的 `contentPadding.top` 会被锚定逻辑吃掉（实测 56dp 与 120dp 渲染完全相同），
   必须 `autoCentering = null` + 列表首位放真实 `Spacer` 占位项。
2. `ScreenScaffold` 的 content Box 不是全屏：在里面 `align(BottomCenter)` 会把浮层顶到页面顶部，
   浮层必须包在 `ScreenScaffold` 外层。
3. `TimeText` 的 `content: CurvedScope.(String) -> Unit` **不是 @Composable**，主题色要在外面取好再捕获。
4. `ActionCard` 的 `onClick` 必须是最后一个参数，否则尾随 lambda 会绑到 `onLongClick`。

M3E Card 默认内边距是"每屏 2~3 项"的密度，文件列表压到 `vertical = 6.dp`（行高 52dp 兜底）。

## 密度调整（同日，用户反馈「纵向高度太大了」）

**根因**：M3E `Card` 的官方最小高度是 **64dp**（`CardTokens.ContainerMinHeight`，
见 compose-material3/tokens/CardTokens.kt:29）。我之前每行都是 64dp，
227dp 圆屏上一屏只放 2 行半。

**对比过的官方高度 token**：
- `Card` = 64dp（CardTokens.ContainerMinHeight）
- `FilledTonalButton` = 52dp
- `CompactButton` = 48dp
- 文件行用 48dp、菜单行用 52dp，都是"官方组件已有的档位"，不是自己拍的数。

**改动**（都在 `ui/common/M3E.kt`）：
- FileCard `.height(48.dp)`，图标 28→24dp，标题 titleMedium(16sp)→titleSmall(14sp)
- MenuCard `.height(52.dp)`，图标 28→26dp，标题同上
- 存储卡 `heightIn(min = 52.dp)`（**不能**用 height()，两行内容会被裁）
- ClockGap 首页 30dp / 其余 26dp，列表间距 5→4dp（浏览页 3dp）

**踩的坑**：存储卡一开始也用了 `.height(52.dp)`，结果进度条被裁掉一截。
两行内容的卡片必须用 `heightIn`，只有单行内容才能用 `height`。

效果：浏览页一屏 2 行 → 3 行；首页 3 张卡。选择态/快捷菜单/长按均正常。

**构建环境补充**：`assembleDebug` 现在也需要 JDK 21 工具链了（之前只有 lint 需要），
必须带：
```
./gradlew :app:assembleDebug --console=plain \
  -Dorg.gradle.java.installations.auto-download=false \
  "-Dorg.gradle.java.installations.paths=C://Users//Administrator//.gradle//jdks//eclipse_adoptium-21-amd64-windows"
```

### AGP 9 开 R8 的三个坑（都是"文档没写"级别的）
1. **`optimization { enable = true }` 必须在 gradle.properties 里加
   `android.r8.gradual.support=true`**，否则直接报
   `Cannot use optimization.enable=true without setting android.r8.gradual.support flag`。
2. **DSL 是 `optimization { enable; keepRules { files(...) } }`**，
   老项目的 `isMinifyEnabled` / `isShrinkResources` / `proguardFiles` 在 AGP 9 里**不存在**。
   `KeepRules` 接口只有 `files` / `ignoreFrom` / `ignoreAllExternalDependencies` 三个可用成员。
   资源裁剪由 `enable = true` 自动接管，没有单独开关。
3. **Gradle Kotlin DSL 里 `java` 会解析到 Project 的 java 插件扩展**，
   所以 `java.util.Properties()` 全限定名反而报 `Unresolved reference 'util'`，
   必须 `import java.util.Properties` 后用短名 `Properties()`。
   另外 import 必须放在 `plugins {}` **之后**。

### 签名配置写法（密钥不进版本库）
`signingConfigs` 里读 `local.properties` 的 release.storeFile / storePassword / keyAlias / keyPassword，
`app/release-key.jks` 已加进 .gitignore。`storeFile` 的 `file()` 是**相对于 app/ 模块**解析的，
放项目根目录会报 "Keystore file not found"。

### 顺带修掉 5 个 deprecated 图标警告
`Icons.Filled.List` / `Icons.Filled.Send` → `Icons.AutoMirrored.Filled.*`
（包名 `androidx.compose.material.icons.automirrored.filled`）。
